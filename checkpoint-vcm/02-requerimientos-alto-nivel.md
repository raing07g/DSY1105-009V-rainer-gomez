# 02. Requerimientos de Alto Nivel

| ID | Requerimiento de Alto Nivel | Descripción |
| :--- | :--- | :--- |
| **RAN-01** | **Exploración de proyectos** | La aplicación deberá permitir a los usuarios visualizar el catálogo de proyectos de innovación de CIM UC. |
| **RAN-02** | **Búsqueda y filtrado** | La aplicación deberá permitir la localización de proyectos mediante texto libre o filtrado por área temática. |
| **RAN-03** | **Consulta detallada** | La aplicación deberá permitir seleccionar un proyecto y desplegar su ficha técnica completa. |
| **RAN-04** | **Navegación simplificada** | La aplicación deberá ofrecer una navegación directa y reversible entre la pantalla principal y la de detalle. |
